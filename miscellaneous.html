Deploy Assistant: An LLM-Powered Terminal Assistant

Fundamentals of Artificial Intelligence, Peking University · Spring 2025
Instructor: Prof. Hao Dong

Code / Report (Chinese)

We developed a lightweight terminal assistant for Windows PowerShell that uses large language models to help users troubleshoot command-line errors, resolve dependency and configuration issues, and plan software deployment. We added short- and long-term memory management to support personalized assistance, and a security module to flag potentially dangerous commands before execution.
