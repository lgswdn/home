# Sources and provenance

## Overall layout and banners

Reference: Yu Deng's homepage, https://sites.google.com/uchicago.edu/yudeng/about-me

The navigation placement, banner height, centered headings, typography, whitespace, and text layout were reconstructed for a plain static website. The three banner files are local copies of images served on his About Me, Research, and Miscellaneous pages, downloaded on 2026-10-10. Their reuse license was not stated on the pages inspected. This record attributes their source; it does not assert a license grant.

## Research code

Source: https://github.com/jonbarron/jonbarron.github.io

`assets/jon-barron.css` is copied unchanged from the repository's `stylesheet.css`. The publication-row markup in `research.html` and `paper-entry-template.html` is adapted from the repository's `index.html`. The repository README explicitly invites cloning the code for personal use: https://github.com/jonbarron/jonbarron.github.io/blob/master/README.md

The placeholder SVG and shared layout stylesheet were created for this website. Lato font definitions in the original stylesheet load from Google Fonts.
